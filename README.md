# Twenty Six Detailing – überarbeitete Website

## Lokal starten

```bash
npm install
npm run dev
```

Alternativ kann der Ordner mit einem einfachen lokalen Webserver geöffnet werden.

## Vor Veröffentlichung erforderlich

- Domain/DNS für `twentysixdetailing.de` prüfen und aktivieren.
- Kontaktformular nach dem Netlify-Deployment einschließlich Bildupload testen.
- Tatsächlichen Hostinganbieter und Netlify Forms in der Datenschutzerklärung konkretisieren.
- Verbindliche Öffnungszeiten ergänzen, sobald festgelegt.
- Echte Paketpreise oder Ab-Preise ergänzen, sobald freigegeben.
- Nur echte Google-Bewertungen mit Profil-Link einbauen.
- Optional eine professionelle Domain-E-Mail und einen verifizierten Instagram-Link ergänzen.
- Prüfen, ob die Impressumsadresse zugleich der öffentlich gewünschte Kundenstandort ist.

## Enthalten

- Responsive Startseite mit klarer Conversion-Führung
- Leistungs- und Paketvergleich ohne erfundene Preise
- Echte Vorher-Nachher-Vergleiche
- Galerie vorhandener Arbeiten
- Über-uns- und FAQ-Seite
- Kontaktformular mit optionalem Bildupload und Honeypot
- Erfolgs- und 404-Seite
- Canonicals, Open Graph, LocalBusiness-Daten, Sitemap und robots.txt
- Tastaturfokus und `prefers-reduced-motion`
